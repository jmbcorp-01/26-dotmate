- 도트메이트를 "웹에이전시"에서 **"SaaS → 자체 AX 시스템 전환 회사"**로 재정의

- 사이트의 KPI는 브랜딩이 아니라 **업무 진단 신청 수와 질**

## 2. 디자인 원칙

- **고객의 실제 화면에서 출발한다.** 추상적인 AI 이미지(노드 그래프, 빛, 파티클, 신경망) 금지
- 색: 흰 종이 `#FFFFFF` / 먹 `#000000` / 인주 빨강 `#D82E28` (점과 "AI가 맡는 업무" 표시에만) / 꺼진 기능 회색 `#C4C4C4`

## 4. 메인 (1개 섹션)

**카피**
> 사업이 커지면, SaaS가 좁아집니다.
> .ax는 우리 사업 방식대로 시스템을 다시 짓고, 그 안에서 AI가 실제 업무를 맡게 합니다.

- CTA: `업무 진단 신청하기` (하나만) / 보조 텍스트 링크 `AX전환이 뭔가요?`
- 라인업: `.ax commerce` `.ax erp` `.ax crm` `.ax edu` (글자 링크)

**애니메이션: SaaS 메뉴가 우리 회사 메뉴로 바뀐다** (쇼핑몰 기준, 한 번만 재생)
1. 범용 쇼핑몰 SaaS 관리자 메뉴 36개가 펼쳐진다
2. 빨간 점이 훑고 지나가며 안 쓰는 메뉴 25개가 회색으로 꺼진다
3. 메뉴에 없어서 엑셀로 하는 일 4개가 바깥에 나타난다 (도매 거래처 단가, 공동구매 정산, 채널별 재고 통합, 맞춤 제작 주문)
4. 꺼진 메뉴는 사라지고, 쓰던 메뉴와 엑셀 업무가 합쳐져 **우리 회사 메뉴 8개**가 된다
5. 빨간 점이 `.ax commerce`의 점이 되고, AI가 맡는 메뉴 5개 옆에 빨간 점과 한 줄 설명이 붙는다

- 다른 라인업(erp·crm·edu)은 같은 문법으로 2차에 추가
- `prefers-reduced-motion` 시 완성된 메뉴만 표시

## 5. AX전환? (/ax)

1. 이런 회사라면 해당됩니다: SaaS 밖에서 덧대는 업무, 이어 붙인 SaaS, 늘어나는 판매 채널
2. 왜 지금 자체 시스템인가 (AI로 짧아진 구축 기간 + 매월 확장하는 구독)
3. 라인업 4종: .ax commerce / .ax erp / .ax crm / .ax edu
4. SaaS vs .ax 비교표
5. **가격표 (공개)** Start 월 99만원~ / Grow 월 199만원~ / Scale 월 390만원~ (더미). 비용 계산기는 쓰지 않음
6. 전환 프로세스 7단계 (무중단 이전 강조)

## 6. 포트폴리오 (/work)

- 필터: `AX` (기본 선택) · `플랫폼` · `디자인`
- **AX:** 상단 넓은 카드. 필수 요소
  - 라인업 태그 (`.ax commerce`·`.ax erp`·`.ax crm`·`.ax edu`)
  - `From [SaaS 유형] → To 자체 시스템`
  - "SaaS 메뉴 → 우리 회사 메뉴" 전후 비교 (메인 애니메이션과 같은 문법)
  - 결과 숫자 1개 (예: SaaS 밖에서 하던 업무 → 시스템 안으로 n개, AI가 맡은 업무 시간)
- **플랫폼·디자인:** 하단 작은 그리드. 이후 AX 전환된 사례는 빨간 점 배지
- 상세 템플릿: 사업 성장 상황 → SaaS의 한계 → 다시 지은 시스템 → AI가 맡은 업무 → 이후 확장 이력 → 결과(숫자)

## 7. 문의하기 (/contact)

첫 질문: **"지금 어떤 SaaS를 쓰고 계신가요?"**

| 항목 | 형식 |
|---|---|
| 분야 | commerce / erp / crm / edu / 기타 |
| 현재 SaaS | 선택 + 직접 입력 |
| SaaS 밖에서 처리하는 업무 | 직접 입력 ("엑셀로 하는 일") |
| 함께 쓰는 SaaS 개수 | 구간 선택 |
| 반복 업무 | 복수 선택 |
| 규모 | 회원 수·월 주문 수·사용자 수 구간 |
| 희망 시기 | 구간 선택 |
| 회사명·담당자·연락처 | 입력 |

- 제출 시 이메일 + 메신저(Slack/카카오워크) 알림
- 2차: 입력값 기반 "우리 회사 메뉴" 초안 즉시 미리보기

## 8. 기술 스택 (제안)

- Next.js + TypeScript (정적 우선, SEO)
- 애니메이션: DOM + Web Animations API (텍스트 메뉴 자체를 움직임, WebGL·라이브러리 미사용)
- 포트폴리오: MDX 또는 헤드리스 CMS
- 배포: Vercel / 폼: API Route → 메일·메신저
