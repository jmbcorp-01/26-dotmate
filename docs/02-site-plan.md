## 4. 메인 (1개 섹션)

**카피 (안)**
> 빌려 쓰던 SaaS에서, 우리 회사 시스템으로.
> 처음부터 AI가 일하고, 운영까지 책임집니다.
> **DOTAX** — 쇼핑몰 · ERP · CRM · 교육플랫폼

- 보조 문장: "구독이 끝나면, 시스템은 고객님 것입니다."
- CTA: `무료 전환 진단받기 →` / 보조 `가격 보기`
- 하단 칩: `Commerce` `ERP` `CRM` `Edu` → 클릭 시 /ax 해당 라인업으로 이동

**애니메이션: 상자에서 나온 점**
1. 회색 템플릿 상자(빌려 쓰는 SaaS) 안에 빨간 점이 갇혀 테두리에 부딪힌다
2. 점이 상자를 뚫고 나온다
3. 점이 지나간 자리에 회사 모양대로 블록이 그려진다 (주문·회원·재고·상담 등)
4. 블록이 연결되고 스스로 움직인다 (업무 자동화)
5. 점이 헤드라인 마침표 / `.ax`의 점으로 안착하며 멈춤

- 특정 SaaS 브랜드·로고는 화면에 쓰지 않음
- 기계적이고 정확한 모션, 짧고 단단한 이징
- 모바일 축약 시나리오, `prefers-reduced-motion` 시 정지 이미지

## 6. 포트폴리오 (/work)

- 필터: `AX` (기본 선택) · `플랫폼` · `디자인`
- **AX:** 상단 넓은 카드. 필수 요소
  - 분야 태그 (Commerce·ERP·CRM·Edu)
  - `From [SaaS 유형] → To 자체 시스템`
  - 결과 숫자 1개 (예: 연 SaaS 비용 절감, 자동화된 업무 시간)
- **플랫폼·디자인:** 하단 작은 그리드. 이후 AX 전환된 사례는 빨간 점 배지
- 상세 템플릿: 문제 → 기존 SaaS → 전환한 시스템 → AI 자동화 → 결과(숫자) → 기간

## 7. 문의하기 (/contact)

첫 질문: **"지금 어떤 SaaS를 쓰고 계신가요?"**

| 항목 | 형식 |
|---|---|
| 분야 | Commerce / ERP / CRM / Edu / 기타 |
| 현재 SaaS | 선택 + 직접 입력 |
| 월 SaaS 비용 (이용료+앱) | 구간 선택 |
| 반복 업무 | 복수 선택 |
| 규모 | 회원 수·월 주문 수·사용자 수 구간 |
| 희망 시기 | 구간 선택 |
| 회사명·담당자·연락처 | 입력 |

- 제출 시 이메일 + 메신저(Slack/카카오워크) 알림
- 2차: 입력값 기반 "예상 절감액" 즉시 미리보기
